# Nivedika Choudhary — Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript. No build step is required.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year

## Deploy on GitHub + Vercel
1. Create a new **public** GitHub repository named `nivedika-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository.
3. Sign in to Vercel with GitHub.
4. Choose **Add New Project**, select `nivedika-portfolio`, and deploy it.
5. Vercel will provide a live URL that you can paste into the college form under **Portfolio / Personal Website**.

## Important
Update the project/certification details if anything changes. Do not add API keys, passwords, or other secrets to this repository.
